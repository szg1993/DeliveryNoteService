# Delivery notes

The language used to describe delivery-note destinations.

## Language

**Recipient**:
A target destination for a delivery, which can be a person or a company.
_Avoid_: Customer, user

**Recipient code**:
A unique identifier for a recipient, entered manually by the user. Letter case and
surrounding whitespace do not distinguish codes.
_Avoid_: Recipient name, generated code

**Foreign recipient**:
A recipient whose destination is outside Hungary, determined by its country.
_Avoid_: Outlander
